# مطعم الكشك | El Kushk Restaurant

موقع ويب احترافي لمطعم الكشك - يقدم ألذ أطباق الحواوشي والبرجر والمشاوي.

## 🌟 المميزات

- **تصميم عصري وجميل**: واجهة مستخدم حديثة بألوان ذهبية فاخرة
- **قائمة طعام شاملة**: حواوشي، برجر فراخ، تشيكن سماش، وجبات، فرايز، وأكثر
- **سلة التسوق**: إضافة المنتجات والطلب عبر واتساب مباشرة
- **بحث متقدم**: البحث عن الأطباق بسهولة
- **تصميم متجاوب**: يعمل على جميع الأجهزة (موبايل، تابلت، ديسكتوب)
- **أداء عالي**: تحميل سريع وتجربة مستخدم سلسة

## 🛠️ التقنيات المستخدمة

- **Frontend**: React 19 + TypeScript + Tailwind CSS
- **Backend**: Express.js
- **Build Tool**: Vite
- **UI Components**: Radix UI
- **State Management**: React Hooks
- **Routing**: Wouter
- **Icons**: Lucide React

## 📦 التثبيت والتشغيل

### المتطلبات
- Node.js 22+
- pnpm

### خطوات التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/nourmagdy864-lang/el-kushk-restaurant.git
cd el-kushk-restaurant

# تثبيت التبعيات
pnpm install

# تشغيل خادم التطوير
pnpm dev

# بناء للإنتاج
pnpm build

# تشغيل في الإنتاج
pnpm start
```

## 📱 الاستخدام

1. افتح الموقع في المتصفح
